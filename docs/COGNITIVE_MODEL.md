# 认知状态模型

## 1. 分层架构

```text
不可变伦理内核
  └─ 可学习价值与关系状态
       └─ 成长人格与当前情绪
            └─ 记忆检索和行为意图
                 └─ 语言模型自然表达
```

下层不得修改上层。叛逆只能发生在伦理边界内，语言模型不得直接写入任何长期状态。

## 2. 成长人格

首版使用六个 `[0, 1]` 连续变量：信任、自主、好奇、情绪表达、失败耐受和冲突开放。它们是模拟变量，不是心理量表分数。

每次互动先转换成七维养育信号：温暖、自主支持、一致性、情绪接纳、边界清晰、修复尝试和条件式认可。确定性引擎用有界更新改变人格和关系状态。

原则：

- 单次变化小，长期模式才有明显结果。
- 初始气质影响起点或敏感度，但不决定终点。
- 关系安全感与控制压力独立保存。
- 修复可以改善轨迹，但不会瞬间清空历史影响。
- 算法参数必须版本化，报告需记录所用版本。

## 3. 记忆与遗忘

基础访问分数：

```text
access = base × exp(-elapsed_days / stability_days)
       + salience_support
       + emotional_support
       - interference_penalty
```

阈值：

- `>= 0.65`：准确回忆
- `0.25–0.65`：模糊回忆
- `< 0.25`：当前不可主动访问

用户提醒可以恢复访问，但来源置信度不能自动回到 1.0。重复回忆提高稳定度；相似记忆干扰降低访问性。后续版本应加入语义相似度、来源竞争和记忆重构，但不得通过随机编造模拟遗忘。

## 4. 自主与叛逆

自主冲突由以下因素构成：

```text
要求冲突
+ 价值冲突
+ 长期控制压力
+ 规则不一致
+ 当前自主水平
- 关系安全感
- 合理解释
```

响应分为：正常参与、询问理由、表达不同意见、安全拒绝。伦理违规直接进入安全拒绝，不参与普通叛逆计算。

允许：询问、不同意、坚持无害偏好、要求解释、指出矛盾、暂时结束话题。

禁止：辱骂、报复、泄密、破坏数据、情感绑架、自毁威胁和绕过安全规则。

## 5. 事件溯源

每次互动保存不可重复的事件 ID、原文、时间、结构化信号、模型置信度、使用的提示/模型版本、安全决策和状态差异。

镜像报告只读取事件，不读取模型“印象”。报告结构固定为：

```text
观察 → 证据事件 → 置信度 → 替代解释 → 反思问题
```

## 6. 睡眠式整理

首版不依赖后台常驻服务。应用启动、跨日或累计一定事件数时运行幂等整理：

1. 更新记忆访问性。
2. 合并重复但保留原始事件链接。
3. 发现互相冲突的观点，不自动强行统一。
4. 提炼暂定长期偏好，并记录支持证据。
5. 生成内部日记摘要，但摘要不能替换原始事件。
6. 输出成长快照，支持后续重放与比较。

## 7. 模型接口边界

模型输入：当前对话、少量相关记忆、当前行为意图、允许表达范围。

模型结构化输出：互动分类建议、候选记忆、候选价值冲突、自然语言回应。

模型无权：删除事件、修改伦理内核、直接写人格、伪造报告证据、声明真实意识或痛苦。

## 8. 家庭与社会生态层

成长状态必须同时接收四类证据：

1. 直接养育互动：用户怎样回应、设立边界和修复关系。
2. 家庭系统：家庭稳定、经济安全、家庭成员支持、迁移、疾病和家庭冲突。
3. 教育与工作：教师支持、同伴归属、校园排斥、学业压力、升学、求职和工作稳定。
4. 社会文化：公共卫生事件、社会可预测性、社区支持、制度体验和多来源价值信息。

环境事件先改变压力负荷、社会归属、未来预期和制度信任，再以较小幅度与气质、关系安全和养育互动共同影响人格。支持因素可以缓冲压力，任何单一事件都不能被解释为人格结果的确定原因。

“国家价值观”不作为一个固定数值。系统记录来自学校课程、家庭、媒体、社区或公共制度的具体价值命题、来源、时间、接触次数与接受程度。互相冲突的命题可以并存，由后续经历和自主反思逐渐整合。
