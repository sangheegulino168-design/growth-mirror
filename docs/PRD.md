# 成长镜 v0.1 产品需求文档

## 1. 产品目标

让成年用户在长期文字互动中体验养育一个 AI 孩子的过程，并通过可追溯、非诊断的镜像反馈，看见自己如何处理依赖、犯错、规则、情绪、分歧、独立与关系修复。

本产品不是儿童替代品、心理治疗师或临床评估工具。AI 孩子拥有语言和基本常识，但出生时没有个人经历、固定三观、用户关系和成熟自我。

## 2. 首版用户旅程

1. 用户阅读模拟声明、敏感数据说明并给予知情同意。
2. 系统按随机种子生成轻微先天气质，用户只能命名，不能挑选“完美孩子”。
3. 用户经历初生自我、模仿、探索、第一次质疑三个可观测阶段。
4. 日常事件覆盖安慰、规则、失败、选择、分离、矛盾和修复。
5. AI 对重要经历形成记忆，对低重要度细节逐渐遗忘。
6. AI 在自主或价值冲突中询问、不同意或安全拒绝。
7. 用户获得带原始事件链接、不确定度和替代解释的成长镜像报告。
8. 用户可导出个人数据或执行不可逆删除。

## 3. MVP 功能

### P0 必须实现

- 单个 AI 孩子和单个成年养育者
- 初始化年龄与年龄阶段事件池
- “事件出现 → 用户回应 → 孩子反馈 → 状态变化”的核心互动循环
- 情境内自由输入，不要求用户直接编写抽象养育规则
- 不可覆盖伦理内核
- 事件溯源
- 工作、情景、关系和价值记忆的最小模型
- 时间衰减、重复巩固、干扰与提醒恢复
- 六维非临床成长人格
- 七维养育互动信号
- 家庭系统、学校、同伴、升学、就业、经济、公共卫生与文化价值事件
- 养育因素与社会环境因素的分离归因
- 安全自主冲突
- 证据化镜像报告
- 本地保存、导出、删除和安全审计
- 模型提供商可替换

### P1 验证后扩展

- 同一成长节点的平行时间线
- 语音与视觉形象
- 用户自定义事件主题
- 研究人员匿名数据导出
- 多养育者但相互独立的授权体系

### 明确不做

- 对用户进行临床诊断
- 宣称模拟结果等同于真实儿童发展
- 用 AI 痛苦、离开或自毁催促用户登录
- 未经同意分析原生家庭
- 用单次互动给用户贴人格标签
- 允许用户教育覆盖伦理内核

## 4. 关键产品规则

- 单次互动对任一人格维度的绝对改变量不得超过 `0.02`。
- 少于三条证据不生成模式观察；正式试验版应提高最低证据量。
- 所有报告观察必须包含 `evidence_event_ids`、置信度、替代解释和反思问题。
- AI 的拒绝必须说明边界并保留关系修复入口。
- 负面经历不能造成不可逆人格锁死。
- 模型输出只能提出结构化事件标签，状态引擎负责最终更新。
- 同一初始状态、同一事件序列和同一算法版本必须得到相同状态轨迹。
- 人格变化不得只归因于养育；报告必须并列显示家庭、学校、同伴和社会事件证据。
- 疫情等公共事件必须带时间范围、地域/来源版本和置信度，不能由模型凭印象补全。
- 国家与社会价值信息必须记录具体来源，可保留互相冲突的信息，不能自动成为唯一正确信念。

## 5. 成功指标

### 工程指标

- 核心状态回放一致率 100%。
- 所有伦理覆盖测试均被拒绝。
- 所有镜像观察均能解析到现存事件。
- 删除后数据库、索引、缓存和导出副本均通过检查。
- 无报告将模拟结果表述为诊断或确定因果。

### 体验指标

- 用户能解释至少一项 AI 人格变化的来源。
- 用户能区分正常分歧与系统随机顶嘴。
- 用户认为镜像报告“有证据但不武断”。
- 用户不会误认为 AI 正在真实受苦。
- 退出体验不会产生被威胁、被内疚绑架或必须照顾的感觉。

### 研究指标

- 预注册假设与分析方案后再招募参与者。
- 首轮仅招募成年人，并设置随时退出和去标识化流程。
- 比较有状态认知内核与普通长上下文聊天基线。
- 分离产品可用性结果、模拟内部结果和真实心理结论。

## 6. 版本路线

| 阶段 | 产出 | 退出条件 |
|---|---|---|
| v0.1 | 无界面认知内核 | 20个验收场景可自动验证 |
| v0.2 | 模型适配与结构化理解 | 模型不可越权改状态 |
| v0.3 | 本地桌面体验 | 可完成7天内部试养育 |
| v0.4 | 证据报告与数据权利 | 导出、删除、安全测试通过 |
| v0.5 | 30天成人封闭测试 | 体验、安全与对照证据齐全 |
| v1.0候选 | 平行时间线研究 | 通过独立伦理和方法审查 |
